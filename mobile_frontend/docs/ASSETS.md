# Assets and notices

Product photographs are bundled from the user-supplied Tech Zone project. Sample catalog names, prices, reviews, stock, and orders are demonstration data. Live mode reads catalog data from the connected server.

Technest icon, splash, and brand mark were created for this mobile frontend. Inter is bundled through `@expo-google-fonts/inter` under the SIL Open Font License. Ionicons are bundled through Expo Vector Icons. Corresponding notices are included in `docs/licenses/`; dependency licenses also ship with installed packages.
